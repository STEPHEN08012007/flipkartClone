# 🛒 Flipkart Clone

A responsive Flipkart-inspired e-commerce website built using HTML and CSS.

## 🚀 Features

- Flipkart-style Navbar
- Search Bar
- Login & Cart Section
- Product Categories
- Product Cards
- Offers & Deals Section
- Footer Section
- Responsive Layout
- Hover Effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Font Awesome Icons
